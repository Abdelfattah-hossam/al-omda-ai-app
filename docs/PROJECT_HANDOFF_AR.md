## أولويات التنفيذ

### أولوية 1 — دورة المشروع الحقيقية
- الطلب ← تحليل المتطلبات ← خطة واضحة ← موافقة المستخدم ← تنفيذ متتابع لكل مرحلة ← إنشاء مخرجات حقيقية ← معاينة وتنزيل ← سجل نهائي.

- ضمان عدم تنفيذ المرحلة مرتين وعدم فقدان checkpoint عند الخطأ أو الإيقاف.

- Word: إنشاء DOCX صالح فعليًا، مع الجداول والتنسيق المطلوب.

### الخريطة العالمية في لوحة التحكم
- **منفذ جزئيًا:** توجد خريطة مرئية داخل لوحة التحكم الرئيسية، بالإضافة إلى صفحة تحليلات المستخدمين.
- **متاح:** أرقام النشاط الحقيقية تأتي من تسجيلات الدخول عبر Supabase للمستخدمين المسجلين.
- **غير متاح/متعذر:** لا توجد إحداثيات مستخدمين حقيقية؛ التطبيق يوضح أن بيانات الموقع الجغرافي لا تُجمع، لذلك لا تعرض الخريطة علامات مستخدمين حقيقيين. لا يجوز إنشاء مواقع افتراضية على أنها حقيقية.
- **متبقٍ:** إذا أُريد عرض مواقع فعلية مستقبلًا، يلزم مصدر موقع اختياري ومصرح به مع موافقة المستخدم وضوابط خصوصية واحتفاظ واضحة؛ لا تُفعّل هذه المجموعة تلقائيًا.
